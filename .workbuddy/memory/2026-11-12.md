## 打包体积与内存分析（只读排查，未改代码）

- `.app` 258MB / DMG 115MB。Electron Framework 239MB（二进制 192MB，已 strip）+ asar 16MB。
- asar 里 12MB 是白带的 `node_modules`（highlight.js 5.2M / katex 3.8M / markdown-it 2M），
  这些库只在 renderer 里被 Vite 打包，main 产物只 require electron/node 内置模块。
  → 把 `dependencies` 移到 `devDependencies` 可省下。
- 实测（/tmp 副本打 dmg）：UDZO 115M / ULFO 114M / **UDBZ 107M**；
  UDBZ + 删 `libvk_swiftshader.dylib`(16M)、`chrome_crashpad_handler`、`default_app.asar` = 101M；
  再去掉 asar 里的 node_modules = **97M**。
- 结论：dmg 换 UDBZ 是最划算的一行改动；97MB 已接近 Electron 44 arm64 下限。
- 内存：`main-window.ts` 构造即 loadURL，close 只 hide，加上 index.ts 四个后台节流开关，
  隐藏页面永远按前台跑。真正解法是「空闲销毁 + 用时重建」（页面按需存在），
  或最终改为接口直连（已有 installApiHeaderHook / fetchHistoryList 基础）。
