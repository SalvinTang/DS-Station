# 快捷窗口展开/收起动效参数

> 当前状态：**动效暂时关闭**，空态 ↔ 有内容态直接切到最终位置。
> 动画代码没有删除，保留在 `src/main/windows/quick-window.ts`，由
> `ENABLE_TRANSITION_ANIMATION` 开关控制。

## 当前行为（动效关闭）

- 空态 → 有内容态：直接变成 420×500，窗口底边比空态低 **30px**
- 有内容态 → 空态（新对话）：直接回到 400×100，回到原空态位置
- 输入框尺寸：400×100
- 消息内容：直接出现，不做淡入

## 动效参数（后续恢复时使用）

| 参数 | 值 |
|---|---|
| 总时长 | 360ms |
| 分段 | 两段，各 180ms |
| 缓动 | swing / ease-in-out |
| 空态尺寸 | 400×100 |
| 有内容态尺寸 | 420×500 |
| 第一步 | 外框 400×100 → 420×120，居中，四周各扩 10px |
| 第二步 | 外框 420×120 → 420×500，底边固定，向上展开 |
| 窗口整体下移 | 30px（含底部 10px 间距） |
| 输入框 | 全程固定 400×100，贴在外框底部，左右/底部各 10px |
| 下移发生的阶段 | 第二步（第一步只有 10px 外框扩张） |
| 消息淡入 | 动画结束后 |
| 反向动画 | 完全镜像同样的几何和时长 |

补充说明：

- 窗口底边最终比空态低 30px；输入框本身因为底部有 10px 间距，实际下移 20px。
- 发送前如果输入框折行、空态窗口高度超过 100，动画开始前会先把高度收回 100（底边不动）。
- 动画中的窗口宽度取偶数、x 由中心反推，避免输入框左右半像素抖动。
- 内框在动画期间保持不透明，不做淡入淡出。

## 代码位置

- 动画实现：`src/main/windows/quick-window.ts`
  - `transitionBounds`
  - `animateExpand` / `finishExpand`
  - `animateCollapse` / `finishCollapse`
- 动效开关：同文件 `ENABLE_TRANSITION_ANIMATION`
- 输入框过渡布局：`src/renderer/quick/style.css` 里的
  `.app.content-enter .composer` / `.app.content-leave .composer`
- 渲染层类名开关（已注释）：
  - `src/renderer/quick/main.ts` 里 `submit()` 的 `content-enter`
  - `src/renderer/quick/main.ts` 里「新对话」的 `content-leave`
- 可调参 demo：`Design/设计稿/快捷窗口展开动效demo.html`

## 恢复动效

1. `src/main/windows/quick-window.ts` 把 `ENABLE_TRANSITION_ANIMATION` 改为 `true`
2. 取消 `src/renderer/quick/main.ts` 里两处 `content-enter` / `content-leave` 的注释
3. 需要调参时，可以先在 demo 里改「整体下移 / 分步或同时 / 总时长」看效果，再同步到代码
